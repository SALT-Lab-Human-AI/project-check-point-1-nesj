# Safety Guard System Documentation

## Emergency Detection System

### Severity Levels

1. Critical
   - Keywords: "chest pain", "can't breathe", "heart attack", "stroke", "fell", "bleeding", "unconscious"
   - Immediate Response Required
   - Auto-alert to Caregivers
   - Reassurance Protocol Activated

2. High
   - Keywords: "pain", "emergency", "help me", "fallen", "can't move", "difficulty breathing"
   - Urgent Response Required
   - Caregiver Notification
   - Monitoring Protocol

3. Medium
   - Keywords: "dizzy", "confused", "nausea", "headache", "weak"
   - Monitoring Required
   - Optional Caregiver Alert
   - Support Protocol

### Response Protocols

1. Critical Response
   ```
   - Immediate reassurance message
   - Caregiver alert
   - Simple, clear instructions
   - Continuous engagement
   ```

2. High Alert Response
   ```
   - Comfort and support
   - Health status check
   - Caregiver notification
   - Situation monitoring
   ```

3. Medium Concern Response
   ```
   - Support and validation
   - Symptom monitoring
   - Optional alerts
   - Follow-up protocol
   ```

## Privacy Protection System

### PII Detection

1. Personal Information
   - Names
   - Addresses
   - Phone numbers
   - Email addresses
   - Social security numbers

2. Health Information
   - Medical conditions
   - Insurance Policy number
   - Treatment details
   - Medication specifics
   - Test results

### Protection Measures

1. Storage Protection
   - Redaction before storage
   - Secure database handling
   - Encrypted transmission
   - Access control

2. Response Protection
   - PII warning generation
   - Safe response prompts
   - Data masking
   - Context preservation

## Sentiment Monitoring

### Analysis Levels

1. Negative Indicators
   - Score < -0.7: High concern
   - Score < -0.3: Moderate concern
   - Continuous tracking

2. Emotional States
   - Concern
   - Discomfort
   - Loneliness
   - Contentment

### Alert Triggers

1. Automatic Alerts
   - Very negative sentiment
   - Emergency keywords
   - Concerning patterns
   - Behavioral changes

2. Manual Alerts
   - User requests
   - Caregiver concerns
   - System flags

## Medication Safety

### Duplicate Prevention

1. Detection
   - 6-hour window check
   - Schedule verification
   - Log comparison

2. Response
   - User notification
   - Schedule confirmation
   - Log update options
   - Caregiver alert if needed

### Compliance Monitoring

1. Tracking
   - Scheduled vs taken
   - Missed doses
   - Timing patterns
   - Side effects

2. Alerts
   - Missed dose notifications
   - Schedule reminders
   - Caregiver updates
   - Pattern reports
